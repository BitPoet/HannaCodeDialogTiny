Use a double underscore to define type, options, description or notes for an attribute.

Example: attribute named 'vegetables'...

1. Inputfield Types

vegetables__type=asmselect

Supported types:

  • text (Default), email, url
  • textarea (Linebreaks get removed)
  • integer (HTML5 Number)
  • checkbox (Single toggle), toggle
  • radios, select, selectmultiple
  • checkboxes, asmselect (Sortable Multiple)
  • pagelistselect, pagelistselectmultiple
  • date, datetime
  • icon (InputfieldIcon)
  • field (Clone existing field, see below)

2. Clone Existing Field

Clone the complete configuration of an existing ProcessWire field:

category=""
category__type=field
category__field=blog_category

3. Options (for Selects, Radios, etc)

A) Simple List:

vegetables__options=Spinach|Pumpkin|Celery

You can also use a comma , separator (legacy support).

B) Key/Value pairs:
Use a colon : to separate saved value from displayed label.

vegetables__options=spinach:Fresh Spinach|pumpkin:Tasty Pumpkin

C) Dynamic Options (via Hanna Code):
You can use another Hanna tag to generate the options string.

vegetables__options=[[_generate_vegetable_options]]

4. Description & Notes

vegetables__label=Ingredients
vegetables__description=Select ingredients for your soup.
vegetables__notes=Pumpkin tastes best in autumn.

5. Date/Time Inputs

For date types, no time picker is shown.

birthday__type=date
birthday__format="d.m.Y"
